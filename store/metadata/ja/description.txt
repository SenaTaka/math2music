スライダーを動かすと数式が変わり、数式が円を描き、円が波形を描き、波形が音を奏でる。Math2Music は、数学がそのまま音楽になるジェネレーティブ・シンセです。

◆ 数式をエディットする
・8本の倍音スライダーで y = Σ aₙ·sin(nx) を直接操作。数式表示がリアルタイムに追随します
・基底波形を選択可能:sin / cos / 三角波 / のこぎり波 / 矩形波
・プリセット8種(Smooth / Punch / Square / Chaos / Saw / Organ / Bell / Pulse)+ランダマイズ
・お気に入り保存でいつでも呼び出し

◆ 音楽として鳴らす
・エピサイクル(回転円)が描く波形が、そのままリアルタイムに音になります
・音階クオンタイズ(ペンタトニック/メジャー/マイナー)で、動かすだけで音楽として成立
・BPM・音域・音量はスライダーで細かく調整。ビートに同期したハプティクス
