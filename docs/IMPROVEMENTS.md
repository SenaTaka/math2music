# math2music 機能改善提案

Web 版(Next.js)と iOS ネイティブ版それぞれの改善提案リスト。
✅ = iOS v1 で実装済み / 🔜 = 今後の候補

## 音楽面

| 状態 | 提案 | 概要 |
|---|---|---|
| ✅ | 音階クオンタイズ | 連続的なピッチ変化をペンタトニック/メジャー/マイナーへスナップし「音楽らしさ」を向上(iOS v1 実装済み) |
| ✅ | カスタム数式エディタ | 倍音スライダー8本(n=1..8)で y = Σ aₙ·sin(nx) を自由編集(iOS v1 実装済み) |
| ✅ | プリセット拡充 | Saw / Organ / Bell / Pulse を追加し計8種(iOS v1 実装済み) |
| 🔜 | 位相スライダー | 各項に φₙ を追加し y = Σ aₙ·sin(nx + φₙ) まで拡張(表示は切替式にして1画面を維持) |
| 🔜 | リバーブ/ディレイ | 空間系エフェクトで SNS 映えする音に(AVAudioUnitReverb ですぐ実装可) |
| 🔜 | polyBLEP バンドリミット | サブオシレータ三角波のエイリアシング除去 |
| 🔜 | ルート音選択 | クオンタイズのルートを A 固定から可変に |

## Web 版固有の改善候補

| 提案 | 概要 |
|---|---|
| 倍音スライダー UI の逆輸入 | iOS 版の8本スライダー+1画面レイアウトを Web にも移植 |
| MP4 録画フォールバック | 現状 WebM/VP9 依存で iOS Safari では録画不可 → MediaRecorder の MP4 対応判定 or サーバサイド変換 |
| PWA 対応 | manifest + Service Worker で「ホーム画面に追加」体験を改善 |
| Formula Param の廃止 | 音声・映像とも合計振幅で正規化されるため一律スケールは実質無効果(iOS 版では廃止済み) |

## iOS 版の意図的な仕様差(Web 版との違い)

- **プリセット切替時に音を再トリガーしない**: Web 版は変更のたびにノードグラフを再構築(0.5秒フェード+アタック)するが、iOS 版はスライダー中心の設計に合わせて音色を連続モーフィングする
- **Formula Param 廃止**: 正規化により実質無効果のため(上記参照)
- **音声結合の正規化振幅**: キャンバス寸法非依存の解析値([-1,1])に統一。ライブ再生と書き出し音声が構成上完全一致する
- **サチュレータ**: 1024点 LUT + 2x オーバーサンプリングではなく直接計算(より高精度)
